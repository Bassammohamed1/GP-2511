# 📱 Possible: AI-Powered Learning Difficulty Detection

**Possible** is a mobile application that leverages Artificial Intelligence to assist in the early detection of:

- 📖 Reading Difficulties (Dyslexia)  
- ✍️ Writing Difficulties (Dysgraphia)  
- ➗ Arithmetic Difficulties (Dyscalculia)  
- ⚡ Attention-Deficit/Hyperactivity Disorder (ADHD)

This tool is designed for educators, parents, and healthcare professionals to help identify children with potential learning challenges, enabling early intervention and support.

---

## 🚀 Features

- ✅ **Early Screening:** Quick and interactive tests to assess learning challenges  
- 🤖 **AI-Driven Detection:** Machine learning models trained on real-world educational and behavioral data  
- 🧠 **Multiple Domains:** Tests tailored to reading, writing, math, and attention analysis  
- 📊 **Instant Results:** Displays risk levels and suggestions based on user performance  
- 📱 **Intuitive Design:** Clean and accessible mobile interface suitable for children

## 🧠 AI Models

The app integrates multiple AI models for analyzing inputs:

- 🖋️ **Handwriting Recognition Model:** Detects writing difficulty from user-drawn shapes/letters (`.h5`)  
- 📚 **Reading Difficulty Model:** Evaluates word recognition and fluency using NLP  
- ➕ **Math Error Pattern Model:** Assesses common arithmetic mistake patterns  
- 👁️ **Attention Tracker Model:** Uses behavioral markers for ADHD screening
